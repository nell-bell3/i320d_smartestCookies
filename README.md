After running the code, you should succesfully have created your own cleaned_dataset and have completed the exploratory data analysis. If the code does not output a CSV, use the cleaned_dataset provided in the git. 
Using the cleaned dataset, load it into the LinearReg_Model_Aurelia.ipynb and see how your results come out.
